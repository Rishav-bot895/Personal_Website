# Personal Website

Retro arcade-inspired portfolio for Rishav Raj.

## Run

Open `index.html` directly in a browser.

No build step or package install is required.

## Files

- `index.html` - page structure and portfolio content
- `styles.css` - monochrome arcade design system and responsive layout
- `main.js` - start screen, command terminal, navigation, modal, and WebGL grid
- `design.md` - design notes and QA checklist
- `assets/` - favicon/logo and resume PDF
